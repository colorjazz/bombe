# Correcteur Express

Application statique (HTML/CSS/JS, sans build) : l'enseignant importe des copies (photos ou PDF),
l'IA (OpenAI, avec la clé de l'enseignant) propose nom, classe, note et commentaire. Résultats modifiables,
sauvegardés localement, export CSV compatible Excel.

Lancer en local : `python3 -m http.server` dans ce dossier, puis http://localhost:8000.
