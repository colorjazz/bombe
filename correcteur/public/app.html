Que veut dire la fiabilité ?

Chaque copie est corrigée deux fois, indépendamment. La fiabilité mesure à quel point ces deux corrections sont d'accord, question par question.

90 % et + Les deux corrections concordent : la note est solide.
80 – 89 % Léger désaccord sur une question : jetez-y un œil.
moins de 80 % Désaccord important : copie signalée ⚠, à vérifier.

Les questions en désaccord sont marquées ⚖, avec la note de l'autre correction. La fiabilité baisse aussi si l'IA signale un doute (écriture illisible, copie incomplète), si le nom est illisible ou si le barème ne totalise pas.

La fiabilité n'existe qu'en mode Approfondie. En mode Rapide, une seule correction est faite : seuls les doutes signalés par l'IA apparaissent.

Exemple : 1 point d'écart sur 20 donne environ 85 %. Une fiabilité élevée n'est pas une garantie : vous restez le correcteur. Un corrigé précis (points par question, réponses acceptées) augmente la fiabilité.
