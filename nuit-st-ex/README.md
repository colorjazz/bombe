# La Nuit à St-Ex

Aventure textuelle (parser) dans la Polyvalente Antoine-de-Saint-Exupéry.

- `moteur.js` : moteur du jeu (lieux, objets, inventaire, variables d'état, parser). Les textes narratifs partent du document de conception, enrichis (Blocs F et H, places publiques, gymnases, plan dans l'agenda, bâton lumineux, poursuite après le fracas du cadenas).
- `index.html` : interface. Ouvrir directement dans un navigateur.
- `test.js` : tests du moteur, `node nuit-st-ex/test.js`.

Commandes : NORD, SUD, EST, OUEST, HAUT, BAS (N, S, E, O, H, B), PRENDRE, REGARDER, LIRE, COMBINER, MANGER, FRAPPER, UTILISER, OUVRIR, ALLUMER, CARTE, INVENTAIRE (I), AIDE, REJOUER.
